# redshift_threshold sensitivity audit

This module is synthetic/conditional only. It does not modify retained observational data or assert new measurements. Assumptions: independent truth-labelled sources for binomial Wilson intervals (Euclid), and approximately weakly stationary cadence-indexed flux for lag estimates (TESS). Missing cadence pairs are not bridged. Pairwise correlation and positive-sequence effective sample size can be biased for sparse windows. Wilson intervals do not account for clustered sources. Tests are deterministic; run with `python -m unittest discover -s research -p 'test_*_20261113.py'` from repository root. Scientific code was developed with AI assistance; review by Biswajit Jana required before merge.
