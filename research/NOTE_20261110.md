# Duplicate-source and dependence sensitivity (10 November 2026)

Issue: #1. Complementary to draft PR #2; no changes to that PR's truth-labelled calibration or to the Q1 observational sample.

Two synthetic diagnostics: (1) collapse repeated source IDs to a descriptive inverse-variance weighted **mean pull per source**, then summarize across unique sources; (2) equal-sized exchangeable-cluster design effect `1+(m-1)rho` and effective sample size. This is a sensitivity exercise, **not** an uncertainty estimate from real Euclid measurements.

Within-source redshift covariance is unknown. The per-source statistic does not calculate a combined posterior uncertainty and must not be used as a calibrated source-level z-score. Design-effect assumptions include equal cluster size and a common intraclass correlation. The SVG illustrates the theoretical effective-n dependence for n=100 and m=5, not catalogue measurements.

Reproduce: `python -m unittest discover -s research -p 'test_group_dependence_20261110.py' -v`. No external data or dependencies.

Provenance: synthetic fixtures only. The retained Q1 sample lacks the flagged population and independent spectroscopic truth needed for an observational comparison.
