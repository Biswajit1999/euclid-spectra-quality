# Redshift reliability under truth and S/N matching (29 October 2026)

Tracked by [issue #1](https://github.com/Biswajit1999/euclid-spectra-quality/issues/1). The existing **real Euclid Q1 tile 102160061** has a degenerate contamination flag (all 6,000 sources clean). Its released redshift is **not an external truth label**. Accordingly **no empirical flagged-minus-clean contrast, calibration or detection** can be reported from that tile. The new functions require an external spectroscopic reference and explicitly fail on degenerate or unmatched groups.

Three independent diagnostics: (1) standardized redshift pulls and empirical 1σ/2σ coverage by group, conditional on externally supplied truth and sigma; (2) Brier score and binned calibration error for the *hypothesis* that `spe_z_rel` represents P(|Δz|/(1+z_true) ≤ 0.15), which is not assumed established; (3) a flagged-minus-clean outlier contrast within common S/N quantile strata, pooled-matched weighted and with a deterministic within-group/stratum bootstrap. Bootstrap intervals do not account for survey selection, spatial correlations, spectroscopic truth error, or instrumental calibration uncertainty. Strata lacking three objects from each group are excluded; the estimand is the **matched subset**, not the original population. If there is no overlap, the calculation raises an error.

Run `pytest -q tests/test_redshift_robustness.py` and `python research/run_redshift_robustness.py --output-dir results/redshift_robustness`. The runner **only generates synthetic truth-labelled sources**, with a seeded 30% flagged-group catastrophic-outlier injection, and saves `summary.json` plus a diagnostic PNG. This is a numerical validation of the proposed method, **not** a Euclid Q1 observational finding. To apply it to real data, acquire an independent spectroscopic truth sample with compatible selection and uncertainty definitions, and obtain a tile with non-degenerate contamination flags. No restricted data are redistributed.
